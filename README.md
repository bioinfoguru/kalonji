## Why Kalonji?

You love notebooks — but you don't love what it takes to run one. Jupyter wants a browser tab, a local server, a kernel babysitter, and half your RAM. Kalonji takes a different path: it's a **native desktop app** that feels like a proper code editor but works like a notebook.

Open it. Pick your Python. Start coding. That's the whole onboarding.

> *Kalonji is a sleek, minimalistic, local-first Python notebook engine — with AI code completion built in.*

## ✨ Highlights

| | |
|---|---|
| 📓 **Jupyter `.ipynb` compatible** | Open, edit, and save real notebooks — no lock-in, no conversion |
| ⚡ **Persistent sessions** | Your variables survive between runs. Iterate, don't re-execute |
| 🐍 **Conda & venv aware** | Pick any interpreter or conda environment from the sidebar |
| 📊 **Rich inline output** | Plots, tables, and tracebacks rendered right in the cell |
| 🪶 **Feather-light** | Under 10 MB. Starts instantly. Sips battery, not RAM |
| 🌙 **Offline-first, dark theme** | Works on a plane. Looks good doing it |
| 🤖 **AI code completion** | Ghost-text suggestions as you type — pause with `Ctrl+Shift+P` |
| 💬 **AI chat** | Hit an error? Click **Ask AI** on the traceback for an explanation + fix, then follow up in the sidebar chat |
| 🎛️ **Widgets** | `+ Widget` cells (dropdown / toggle / file / slider) bound to kernel variables — edits push live, no Run needed; rename cleans the old name |

## 🚀 Get started in 30 seconds

1. **[Download](https://github.com/bioinfoguru/kalonji/releases/latest)** the installer for your platform (`.exe` / `.msi` for Windows, `.AppImage` / `.deb` for Linux, `.dmg` for macOS)
2. Launch Kalonji, open an existing `.ipynb` — or start a fresh one
3. In the sidebar, pick your **Python kernel** and click **Start**
4. Write Python in a cell, hit **`Shift+Enter`**, and watch it run

```python
# That's it. You're doing science.
import matplotlib.pyplot as plt
plt.plot([1, 4, 9, 16, 25])
plt.show()
```

## ⌨️ Shortcuts you'll actually use

| Shortcut | Action |
|---|---|
| `Shift+Enter` | Run the current cell |
| `Ctrl+S` | Save the notebook |
| `Tab` | Accept AI ghost-text suggestion |
| `Ctrl+Shift+P` | Pause / resume AI completion |
| `Esc` | Clear the ghost suggestion |
| `Ctrl+=` / `Ctrl+-` | Zoom UI in / out (100–130%) |
| `Shift+Tab` | Signature help at a call (Jedi) |
