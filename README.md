# PyEdit

PyEdit is a lightweight desktop notebook application for writing and running Python code locally.

## Features

- Jupyter notebook (`.ipynb`) support
- Persistent Python sessions
- Code and Markdown cells
- Inline output, plots, tables, and errors
- Conda and Python environment selection
- Notebook open and save support
- Dark theme with adjustable editor font size


Select a Python interpreter in the sidebar, choose a working directory if needed, and click **Start kernel**. Write Python code in a code cell and run it with the cell’s run button or `Shift+Enter`.


## Keyboard shortcuts

- `Shift+Enter` — run the current cell
- `Ctrl+S` — save the notebook
- `Cmd+S` — save the notebook on macOS
